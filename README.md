# Nails by Anter — Luxury Nail Art Studio Website

A responsive website for a premium nail art studio. It uses HTML5, Tailwind CSS 3 and vanilla JavaScript, with a small Node.js (Express) server and a PostgreSQL database that power the **gallery** and its **admin panel**.

```bash
npm install          # first time only
cp .env.example .env # then set DATABASE_URL, SESSION_SECRET, ADMIN_USER, ADMIN_PASS
npm run seed         # creates the database + tables, imports the starter images, creates the admin user
npm start            # http://localhost:5173  ·  admin panel: http://localhost:5173/admin/  (npm run serve does the same)
npm run build        # rebuild HTML pages + minified CSS after editing src/
npm run dev          # watch src/ and rebuild HTML + CSS on change
```

### Gallery admin

Go to `/admin/` and log in with `ADMIN_USER` / `ADMIN_PASS` from `.env`. Running `npm run seed` again resets that password and leaves existing images untouched.

- **Upload:** drag in JPG, PNG or WebP files (8 MB max each). Each one gets a title and alt text, and the batch gets style tags, which drive the gallery filters. Files are resized to a maximum of 1600px, converted to WebP and stored in `assets/images/gallery/`. New uploads appear first.
- **Reorder:** drag the tiles, then click **Save order**.
- **Edit / Hide / Delete:** each tile has these buttons. "Show on home page" puts an image in the home page preview, which shows the first 8 in gallery order.

The public pages read images from `GET /api/gallery` (`?home=1` for the home preview). The code is in `server/` (Express app, routes, `schema.sql`, `seed.js`) and `admin/` (admin UI).

Deploy by running `npm start` on the server (for example with PM2 behind Nginx or Apache) and setting `NODE_ENV=production`, which enables secure cookies. Back up the database and `assets/images/gallery/` together.

> **Edit pages in `src/`, not in the root.** The root `*.html` files are generated by the build and get overwritten.

## 3. Page front-matter

Each `src/pages/*.html` file starts with:

```html
<!---
{ "title": "…", "description": "…", "nav": "gallery",
  "scripts": ["gallery.js"], "noStickyCta": false, "noindex": false, "head": "" }
--->
```

`nav` adds `aria-current="page"` to the matching link in the header, drawer and footer.

## 4. Go-live checklist

- [ ] **Photography.** All images in `assets/images/` are crops taken from the reference design and are low-resolution placeholders. Upload real gallery photos through `/admin/` and delete the placeholders there. For the other page images, export WebP at about 1600px on the long edge for heroes and 800px for cards, and keep the same file names or update the `src/` references. You also need an artist portrait for the About page and photos of the studio interior.
- [ ] **Domain.** Set `SITE_URL` in `scripts/build-html.mjs`. Update `robots.txt`, `sitemap.xml` and the JSON-LD in `src/pages/index.html`.
- [ ] **Business details.** The phone (+91 98765 43210), email, street address, hours, social URLs, artist names, prices and stats are all placeholders.
- [ ] **Forms.** Add `data-endpoint="https://…"` to the contact `<form>` and to `#booking-form` (Formspree, Getform or your own API). Without it, submissions are only simulated. The booking form posts JSON containing name, phone, email, notes, service, artist, date, time and price.
- [ ] **Booking availability.** Availability is simulated in `booking.js` (`slotsFor`). Connect it to your scheduling backend or calendar (Google Calendar, Fresha, Square and so on).
- [ ] **Map.** The contact page embeds a keyless Google Maps search iframe. Swap it for your exact Place embed URL.
- [ ] Run `npm run build` after every change in `src/`.

## 5. Browser support and quality notes

- Works in current versions of Chrome, Edge, Firefox and Safari. Some extras are progressive enhancements: the animated accordion height needs `interpolate-size`, and option-card selection styling uses `:has()`.
- Accessibility: skip link, a single `<h1>` per page, visible focus states, a focus-trapped mobile menu, a native `<dialog>` lightbox, ARIA live regions in the booking summary and gallery status, `prefers-reduced-motion` support, and touch targets of 44px or more.
- Performance: CSS is about 12 KB gzipped. JavaScript is vanilla with no dependencies and loads with `defer`. Images are lazy-loaded with explicit sizes, and the hero image is preloaded.
- SEO: unique titles and descriptions, canonical and Open Graph tags, `NailSalon` and `FAQPage` JSON-LD, a sitemap and robots.txt.
